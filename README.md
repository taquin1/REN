# לב חם ❤️ — אתר היכרויות חינמי

אפליקציית רשת חד-עמדית (SPA) להיכרויות, נבנתה ב-React + TypeScript + Tailwind CSS.

## ✨ תכונות עיקריות

- **פרופיל אישי**: יצירה ועריכה של פרופיל עם תמונה, ביו, גיל ותחומי עניין.
- **גלישת פרופילים**: צפייה בפרופילים של משתמשים אחרים בכרטיסיות אלגנטיות.
- **מערכת התאמות (Matches)**: החלק ימינה ללייק ושמאל לדילאייט, עם אנימציות חלקות.
- **ממשק בעברית**: תמיכה מלאה ב-RTL ובעיצוב מותאם לעברית.

## 🛠️ טכנולוגיות בשימוש

- React 19
- TypeScript
- Tailwind CSS
- Framer Motion (לאנימציות)
- Lucide React (לאייקונים)
- shadcn/ui (לרכיבי ממשק משתמש)

## 🚀 איך להריץ

1. התקן את התלויות:
   ```bash
   npm install
   ```
2. הרץ את שרת הפיתוח:
   ```bash
   npm run dev
   ```
3. פתח את הדפדפן בכתובת שמופיעה בטרמינל (בדרך כלל `http://localhost:5173`).
