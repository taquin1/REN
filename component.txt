
## 🚀 איך להריץ

1. התקן את התלויות:
   ```bash
   npm install
   ```
2. הרץ את שרת הפיתוח:
   ```bash
   npm run dev
   ```
3. פתח את הדפדפן בכתובת שמופיעה בטרמינל (בד"כ `http://localhost:5173`)

## 📝 הערות

- האפליקציה משתמשת בנתונים מקומיים (Mock Data) ואינה מבצעת קריאות רשת אמיתיות לשרת.
- שיחות הווידאו וההתראות הן סימולציה בצד הלקוח לצורכי הדגמה.
- העיצוב מותאם לעברית (RTL) ולנייד (Mobile-First).
